# Security policy

This repository is an experimental protocol specification and reference validator, not a sandbox or security enforcement product. See [spec/10-security.md](spec/10-security.md).

Privately report vulnerabilities that could cause schema-validation bypass, unsafe reference-library behavior, dependency compromise, or misleading security claims to the maintainers through the hosting platform's private security-reporting feature. Do not include real credentials or exploit third-party systems. Maintainers will acknowledge reports when project capacity permits; v0.1 makes no response-time commitment.

Protocol conformance does not certify runtime enforcement. Applications must independently enforce authority, isolate untrusted work, authenticate peers, and validate artifacts.
